# Email-Feedback
<p>A modern, animated 3D Feedback Popup built using HTML, CSS, and JavaScript, featuring star rating, dark/light mode toggle, particle background animation, and EmailJS integration for sending feedback directly to email — without any backend.</p>

 <h2>🚀 Features</h2>

  <h3>🎨 Modern UI / UX</h3>
  <ul>
    <li>Glassmorphism modal popup</li>
    <li>Smooth 3D tilt animation on hover</li>
    <li>Gradient buttons & clean layout</li>
  </ul>

  <h3>⭐ Star Rating System</h3>
  <ul>
    <li>1 to 5 star rating selection</li>
    <li>Hover & selection effects</li>
  </ul>

  <h3>🌙 Dark / Light Mode Toggle</h3>
  <ul>
    <li>One-click theme switch</li>
    <li>CSS variables based theme system</li>
  </ul>

  <h3>✨ Animated Particle Background</h3>
  <ul>
    <li>Floating particles for premium look</li>
  </ul>

  <h3>📧 EmailJS Integration</h3>
  <ul>
    <li>Sends feedback directly to your email</li>
    <li>No backend or server required</li>
  </ul>

  <h3>📱 Fully Responsive</h3>
  <ul>
    <li>Works smoothly on mobile, tablet, and desktop</li>
  </ul>

 <h2>🛠️ Technologies Used</h2>

<ul>HTML5</ul>

<ul>CSS3 (Animations, Variables, Flexbox)</ul>

<ul>Vanilla JavaScript</ul>

<ul>EmailJS (Client-side email service)</ul>
